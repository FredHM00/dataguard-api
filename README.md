# DataGuard API

API REST educacional para gerenciamento de registros fictícios de atendimento,
com autenticação JWT, criptografia de observações sensíveis e trilha de auditoria.

> Projeto de portfólio (nível júnior) — **em construção, Etapa 1**.
> Documento completo de instalação e uso será finalizado na Etapa 6.

## Stack

Python 3.12 · FastAPI · PostgreSQL 16 · SQLAlchemy 2.x · Alembic · Pydantic ·
PyJWT · Argon2 · Fernet · pytest · Docker Compose — desenvolvimento em Ubuntu no WSL 2.
